What is actually shared?

Five immutable columns: time, service, level, latency, and message. Search and summary workers receive the same snapshot descriptors. They send row indices and small aggregates back. The UI reads only visible records.

Strings can decode into local values. Views, messages, and result arrays still allocate. This is not a zero-allocation claim or a log storage service.

Connection and calculation log

    One allocating owner; three readers (UI, search, summary). At most one query pair runs at a time, with one latest pending request. Freeze pins a real snapshot record; it does not use an unimplemented task .at() API. Stop terminates all owned workers and releases retained views. Garbage collection is not forced.
