The prior baseline validated all output entries, not full transport. The raw-leaf reuse from #92 already exists on main; duplicate index allocation and staging are distinct headroom.

The experimental candidate on this proof branch canonicalizes reachable HAMT branch and collision records and caches relocated addresses across distinct retained object-map roots. It leaves single/alias/journal/mixed/nested/sorted paths on the old code. It deliberately does not introduce a wire format change. This is a screening implementation, not a production-ready contract: malformed/custom descriptors, source identity, read-only sources, allocation failure, collision and overlay behavior, transport and iteration order require deeper review before a runtime PR. The paired experiment adds sparse/tile churn/dense controls, independent baseline/control/candidate bundles, exact record verification, transport validation per case/arm, and A/A. Heap/RSS readings are observations, not peak-memory measurements. No merge or deployment is authorized by this proof.
