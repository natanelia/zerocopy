Hypothesis: in multi-layer/tile applications a sparse edit to one of many independently retained arenas may cause every worker to reconstruct an Arena/WASM instance for every incoming descriptor, even when the root and backing memory are unchanged. Current `connectSharedSession` reconstructs via `initWorker` then preserves old top-level identities. None establishes that this cost dominates repeated useful answers in actual two-worker sessions after #97/#98. No production change until baseline evidence shows a meaningful opportunity.
