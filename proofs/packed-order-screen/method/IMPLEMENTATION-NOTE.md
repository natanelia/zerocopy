# Prospective implementation clarifications

Frozen before any packed performance data. This note applies the revision-2 assessment and its independent review without changing any sample count, metric, workload, threshold or ceiling. The historical original assessment is preserved in the source history. The current public METHOD.md changes only evidence-scope prose; all scientific definitions, conditions and thresholds remain unchanged.

1. All intervals are two-sided. Eight independent process pairs imply df=7. Ordinary harm uses t(7, 0.975); simultaneous memory uses t(7, 1 − 0.05/(2×22)); simultaneous latency uses t(7, 1 − 0.05/(2×38)). Memory and latency are separately controlled 95% families, not one joint 95% guarantee. Independent numeric validation is preserved in statistics/. Exact agreement of these literals with the final implementation remains part of the proposed inert gate before release.
2. Timing eligibility is for the entire engine/endpoint. Any applicable calibration, resolution or bracket-overhead failure leaves that endpoint unresolved. Preserve its full raw observations and failure reasons; never drop a pair/chunk or infer on a favorable subset. Import has one observation per comparison child, no cached repeat, no K ladder and no 5 ms floor.
3. GC, memory and timer instrumentation plus retained measurement bookkeeping are initialized before the startup before-import sample. The target public library first loads inside the single timed import bracket, before fixtures. Keep both startup memory states and all component values. GCs stay outside the import timer.
4. Node-only provisional benefit and strong clearance are different dispositions. Mandatory fresh admission probes, complete source/process/custody/correctness integrity, and valid Node P attribution/material benefit remain necessary. Every independently valid material harm vetoes advancement. A failed Bun case attribution guard stays invalid/unresolved, supports no Bun benefit or cleared control, and prevents strong clearance; it does not erase independently valid Node P benefit. Invalid nonprimary evidence never supplies positive support. Preserve all raw states and require a separate source-backed raw accounting review before a final scoped-lead disposition. Contradictory unexplained accounting shifts block that disposition. An invalid endpoint cannot be relabeled as merely a wide valid interval. No samples are removed, no new observations added, and no admission failure is waived.
5. Strong scoped screen clearance additionally requires both admitted memory scopes, every specified memory limit and all 38 latency controls to clear. Neither outcome sets publication, production, merge-readiness or general no-regression permission. Any scoped draft must lead with the measured engine, fixture and forced-GC retained-memory scope and prominently list unresolved/invalid controls and Bun coverage limitations.
