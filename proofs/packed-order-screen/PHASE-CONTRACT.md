# Exact phase and output contract

Scientific process order remains probes Node/Bun, calibrations Node/Bun, then pairs 0–7 with alternating engine-first order and AB/BA arm order. A comparison's seven legacy latency cases rotate by pair index modulo seven. Its first/full endpoint order alternates. Appended close cases are N4096, N4097, N8193, P, reversed when full precedes first. The memory order is fixed E0, N1, N32, N4096, N4097, N8192, N8193, P. There are no adaptive choices.

Comparison phase caps are startup 5 s, setup 20 s, memory 30 s, latency 25 s, final 5 s, owned exit 5 s. Startup includes instrumentation, all retained ledger allocation, oracle bookkeeping, clock diagnostics, the before-import four-pass collection/sample, one timed target import and the after-import four-pass collection/sample. No target module is imported by helper initialization. Calibration has no startup observation; its one target import is ordinary untimed setup.

A comparison emits one startup receipt with the exact before/after records and single import endpoint summary, one memory receipt after all nine cycles have released their iterator, 180 iteration sample records in the frozen plan order, and one final result. Startup is an additional nineteenth endpoint, not an iteration sample. Each of the eighteen iteration endpoints preserves four warmup durations and six measured durations, with the mean of all six as the process observation. Memory receipt identity and startup receipt identity must match the final result exactly.

Timing eligibility is endpoint-wide at analysis: any pair/arm failure of fixed K, applicable calibration floor, positive duration, resolution or overhead leaves the whole engine/endpoint unresolved. Every raw observation remains preserved. The baseline calibration's 5 ms verification floor does not apply to the single fresh import duration. Both timer criteria are 0.5% of each applicable bracket: isolated first-next divides the chunk duration by K; aggregate lifecycle/traversal and import use their complete bracket.

Each memory case holds numeric before/rawPaused/paused/released records only. P has two cycles, all other sizes one. E0 has no suspended successful yield; its completion is validated. N1 verifies completion on resume. Every other memory case validates the second pair of the same iterator before return/holder clear. RawPaused is present only for P, N4096, N4097, N8192 and N8193. It is sampled synchronously after pause, before any GC, and never enters a retained decision contrast or a peak claim. Arena used bytes/capacity remain unchanged in every fixed state and across cases.

Released-minus-before is reported and guarded independently; it is never subtracted from paused-minus-before. Node guards its total, heapUsed and external separately. Bun guards heapSize and extraMemorySize separately. Case limits are 64 KiB for P, 512 bytes for E0/N1/N32, 2 KiB for boundaries. Tight natural drift gives invalid attribution, not zero regression or a passing control.

All native builds, typechecks, full ordinary correctness suites and real worker proofs occur in the separately bounded prepare path. None calls subject.main, performs timing self-checks or contributes a scientific process observation. Scientific startup requires exact prepare receipts, all six passing correctness commands and every prerequisite review/release pin.
