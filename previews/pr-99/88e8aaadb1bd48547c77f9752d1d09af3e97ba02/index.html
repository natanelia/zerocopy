Immutable collections for Node.js workers, Web Workers in the browser, and Bun workers.Immutable
collections for
Node.js workers.

A JavaScript and TypeScript library for sharing maps, lists, and sets across workers. With shared memory, workers read snapshots without copying the whole collection.

Quickstart →
npm i zerocopy

One writer.
Many readers.

A writer publishes immutable snapshots. Readers can keep an earlier version while updates arrive. Use the storage model to see what each worker holds when sharing or cloning.

Node.js supports shared storage. Browsers require cross-origin isolation. Bun copies snapshots by default.
