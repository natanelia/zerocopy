THE SMALL PRINT IS THE POINT

What this actually measures.

End-to-end fan-out and reads. Not a pure transfer benchmark. Not a memory benchmark.

Included

Snapshot descriptor creation, sending to all readers, structured cloning or shared attachment, a lookup for every key, and the response. Shared attachment creates new read-only views on each trial.

Excluded

Worker startup and library loading happen before warm-up. Dataset construction happens once, with its own reported timing. It is not included in the comparison bars.

Same job. Checked answers.

Both paths use the same deterministic string keys and numeric values. Each reader reports a checksum. A mismatch fails the run. Measurement order alternates, and the median and interquartile range use all seven samples.

No universal winner

Native Map can win, especially for small data. Warm-up does not remove per-publication attachment costs. This test does not measure persistent edit history, every value type, or your application's workload.
