Memory method & controls

Absolute process RSS includes the owner, all readers, and the Node runtime. The charts use the same zero-based scale and compare matched reader counts after the first edit. All implementations retain revision 0 and revision 1. Native Map, Immutable.js, and Immer send only the 100 changed records on updates.

The owner-only control uses 158.19 MiB for ZeroCopy SharedMap and 143.25 MiB for native Map. These historical measurements use runtime 8ad5788, before later optimizations. They do not measure the current product catalog or this browser.

Each bar is the median of three fresh processes. Raw data contains every sample, observed ranges, source hashes, and environment. The separate eight-reader recording uses a different host and remains in the full report.
