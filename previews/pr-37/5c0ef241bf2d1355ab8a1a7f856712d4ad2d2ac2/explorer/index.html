Why a map?

Feature IDs are stable keys. Workers fetch a small set of attributes from a large registry. Sparse edits replace objects at existing keys; SharedMap preserves earlier roots. Native Map copies its index once to preserve the initial revision, then updates its current index in place. All replica paths send only changed records on edits.

Bounds are sample attributes, not a spatial index. SharedMap decodes and caches JSON on each reader. Arena allocations remain until the arena is released or compacted.
